# Recall Studio — Product context

**What it is.** A local-first, keyboard-first active-recall workstation for one learner. Thousands of AI-generated questions (8 types) are imported as JSON, studied with FSRS spaced repetition (ts-fsrs), tested in exam mode, and analysed in Insights.

**Who uses it.** A single learner studying 30–120 minutes a day, mostly in Korean (English must read equally well), at a laptop with the keyboard; sometimes on a phone.

**Primary jobs (in order).**
1. Study today's due cards fast: answer → see verdict + explanation on the same screen → rate recall (Again/Hard/Good/Easy) → next. 100% keyboard.
2. Import a batch of questions an external LLM generated (paste JSON, validate, commit).
3. Take a timed exam on a deck and review mistakes; retry the wrong ones.
4. See honest progress: due counts, accuracy with denominators, FSRS-estimated retention clearly labelled as an estimate.

**Non-goals.** Multi-user, cloud sync, in-app LLM calls, payments, building questions one by one in a GUI.

**Mode.** Operate (a tool people work in). Familiar affordances, precision over expression, density where useful.

**Voice.** Plain Korean UI copy, sentence case, verbs on buttons ("제출", "정답 공개", "가져오기 확정"). Errors name the problem and the recovery.
